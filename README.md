# ANGEL MOON — Fashion • Style • More

**Proyecto Final • Curso: Servicio al Cliente • Año 2026**

Sitio web oficial de la boutique femenina **ANGEL MOON**, desarrollado en **HTML5, CSS3 y JavaScript puro** (`index.html`, `styles.css`, `script.js`) siguiendo la regla de diseño y color **60-30-10** extraída del logotipo oficial (`logo.png`).

## Características Principales

- **Regla de Color 60-30-10**:
  - **60% Dominante**: Marfil cálido y blanco limpio (`#FDF9F7` / `#FFFFFF`).
  - **30% Secundario**: Rosa seda empolvado (`#F6E3E0` / `#ECCFD0`) y vino espresso (`#382227`).
  - **10% Acento**: Oro rosa metálico (`#B86D78` / `#9B545F`).
- **Indicador de Horario en Vivo**: Muestra automáticamente si la tienda está *Abierta ahora* o *Cerrada ahora* (`Lunes a Sábado, 9:00 a.m. – 6:00 p.m.`).
- **Catálogo Interactivo + "Mi Lista de Prendas" (`localStorage`)**:
  - Filtros por categoría (`Todos`, `Blusas y Tops`, `Vestidos y Conjuntos`, `Pantalones y Jeans`, `Accesorios / Temporada`).
  - Selección de talla y modalidad (`Apartado 50%` o `Compra completa`) con cálculo automático del total y del 50% de apartado.
- **Conexión Profesional a WhatsApp API (`https://wa.me/50670973956`)**:
  - Toda la lista de prendas seleccionadas y los datos de la clienta se guardan en la página y se envían estructurados a WhatsApp con un solo clic.
- **Asistente Virtual de Moda Dual**:
  - **Modo Preguntas Frecuentes (FAQ)**: Respuestas inmediatas sobre precios, tallas, métodos de pago (`SINPE Móvil` y `Efectivo`), apartados del 50% y entregas en Parque Central (San José) los sábados desde mediodía o envíos.
  - **Modo Pedido Paso a Paso (5 niveles)**: Guía a la clienta validando nombre, teléfono, correo, categoría y detalles, autollena el formulario inferior y genera la ficha lista para enviar a WhatsApp.
